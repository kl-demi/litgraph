## Graph rendering of query results

### Functional

- Design the dashboard like a website: 
- Node limit should be configurable.
- Clicking on a node shows a sidebar in the graph itself containing its full name
and an option to visit the full page for it. The graph itself already has this sidebar
but it's ugly and not informative. Remove the actual sidebar on the dashboard itself.
- Headings/titles/paragraphs should be neutral, simple, no figurative or rhetoric language.

### Stylistic 
- Professional color scheme for nodes/edges, should match the color on its card 
in the database section.
- Graph background/font shares the same theme as the dashboard itself: powerful, 
fast, reliable.
